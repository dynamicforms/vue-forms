# Security Policy

## Supported versions

| Version | Security fixes |
|---|---|
| 3.x, pre-releases included (`next`) | yes |
| 2.x and older | no |

## Reporting a vulnerability

Report it privately through
[GitHub's vulnerability reporting](https://github.com/dynamicforms/vue-forms/security/advisories/new),
not in a public issue. Include the affected version and a minimal reproduction.

A confirmed vulnerability is fixed in 3.x and published as a GitHub security advisory.
